# Heaven's Cloud

Heaven’s Cloud is a mobile application built using MIT App Inventor to enhance customer engagement and user experience in a restaurant setting. It offers a seamless digital interface for browsing menus, placing orders, tracking bills, and completing payments.

---

## Project Objectives

- Increase customer engagement and loyalty
- Promote digital menu browsing and ordering
- Facilitate online payments
- Enable real-time location tracking
- Support restaurant marketing initiatives

---

## Key Features

- Login Page with captcha validation
- Menu Display with swipe navigation
- Search and Filter options
- Billing Page with checkbox-based item selection
- Integrated Payment Gateway
- Live Location Tracking using maps and sensors

---

## Technology Stack

- MIT App Inventor
- CloudDB and TinyDB for data storage
- com.KIO4_AniGif extension for GIF support
- LocationSensor for live tracking
- Notifier and Clock components for sound alerts
- Built-in Player for background audio

## How to Run the Project

1. Download the [`restaurant.aia`](./restaurant.aia) file.
2. Visit [MIT App Inventor](https://ai2.appinventor.mit.edu).
3. Log in with a Google account.
4. Navigate to **Projects > Import project (.aia) from my computer**.
5. Upload the file and open it to begin development or testing.

---

## Troubleshooting

- The Payment Gateway may take a few minutes to load due to network latency or server performance.
- In case of delay, refresh the app or check internet connectivity.
- If the issue persists, close and reopen the app.
